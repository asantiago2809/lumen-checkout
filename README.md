# Lumen Checkout

Original mobile-first product checkout built with React, Redux Toolkit and a NestJS API. Payments run exclusively in a sandbox. This repository is under active development; a passing assessment or live deployment is not yet claimed.

## Privacy

The source assessment and its shared credentials are external to this repository. Copy only variable names from `.env.example` and configure secrets locally or in the hosting provider. Never enter real card data into the sandbox.
