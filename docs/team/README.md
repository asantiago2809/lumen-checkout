# Mesa de trabajo

El director define el plan y los contratos. El coordinador ejecuta sus repartos respetando cuatro agentes activos como máximo. Los roles se alternan por fases; no se simula que todos trabajan simultáneamente. Los prompts de esta carpeta son instrucciones persistentes y reutilizables. El auditor y QA conservan independencia de los autores de implementación.

## Fases
1. Auditoría del enunciado, arquitectura, diseño y entorno.
2. Desarrollo backend y frontend conforme a contratos comunes.
3. Pruebas independientes, correcciones y cobertura.
4. Historial Git, integración y despliegue.
5. Auditoría final por requisito, informe de mejoras y preparación de entrega.

## Formato de relevo
Objetivo y requisitos atendidos; archivos propios; cambios concretos; comandos y resultados reales; defectos; dependencias; siguiente responsable. Ningún porcentaje o estado aprobado se declara sin evidencia.

## Intervención del candidato
Confirmar fecha límite, cuenta de GitHub y alojamiento disponible. Autenticarse por el mecanismo oficial si hace falta. Revisar y comprender decisiones para la entrevista. Las credenciales se configuran localmente, nunca en esta documentación.
